# Escalation: what always needs a human

Skills check intake and draft against this table. When a trigger fires, the skill stops, marks the draft "needs review", and names the route.

| Trigger (observable) | Route | Why |
|---|---|---|
| No pillar can be named for the output | do not ship | Not our story to tell |
| New product, feature or project name | {{CORE_OWNER}} | Naming is identity work |
| Security vulnerability or incident | project owner + security lead | Trust stakes |
| Pricing, licensing, legal or partnership terms | leadership | Commitments |
| A competitor or company named critically | leadership sign-off | Evidence bar; no solo call-outs |
| Rubric self-score below 3 on any axis | requester's reviewer | Honest about reliability |

## Fallback
While waiting, the requester gets the draft clearly marked, plus the reviewer's name and expected turnaround.
