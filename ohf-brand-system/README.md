# Open Home Foundation brand system

The shared core, one directory per project voice, dated truths, annotated examples and self-serve skills, written for agents to load and act on. Start at `INDEX.md`.

## Install
```
/plugin marketplace add <org>/open-home-foundation-brand-system
/plugin install open-home-foundation-brand-system
```

## Maintained with
The brand-system-builder plugin. New projects through `onboard-project`; corrections through `promote-correction`; new skills through `codify-workflow`; monthly health through `audit-brand-system`.
