# Home Assistant: story

For about pages, backgrounders and talk intros. Sourced from Wikipedia (https://en.wikipedia.org/wiki/Home_Assistant), the GitHub API (https://api.github.com/repos/home-assistant/core) and the home page (https://www.home-assistant.io/). Confirm with the founder before public use.

## Origin
Paulus Schoutsen created Home Assistant as a Python application in September 2013 and first published it on GitHub in November 2013. It is licensed under the Apache License 2.0.
