# Home Assistant: naming

## Canonical
- Full name: Home Assistant. Two words, both capitalised, always.
- Short name: none. Project names are never shortened in public writing, ever; "HA" belongs to community speech only (interview 2026-09-14). This applies to every Open Home Foundation project and is proposed for `core/voices.md`.
- In a sentence: "Home Assistant 2026.9 is out."
- The suite and the software: since January 2020, "Home Assistant" is the full product and "Home Assistant Core" is the Python application at its centre (https://en.wikipedia.org/wiki/Home_Assistant). Other named parts: Home Assistant Operating System, Home Assistant Supervisor, Home Assistant Cloud (by Nabu Casa), Home Assistant Companion apps, Assist, Home Assistant Cast. The current official list is an open follow-up in PROJECT.md.

## Feature naming
Integrations are named for the brand or service they connect and link to their documentation page on first mention (documentation standards). Brand names take the brand's own capitalisation. Features shipped in releases are named in sentence case ("Active alerts", "Sources pane", "tile card"). Confirmed in interview 2026-09-14.

## Forbidden variants
| Do not write | Write instead | Why |
|---|---|---|
| HomeAssistant, Homeassistant | Home Assistant | the name is two words |
| Hass.io | Home Assistant Operating System, or Home Assistant | retired in the January 2020 rename (https://en.wikipedia.org/wiki/Home_Assistant) |
| HASS, hass | Home Assistant | internal shorthand only |
| Home-Assistant | Home Assistant | hyphen only in URLs and handles |

## Attribution
Conforms to the core co-branding standard. The canonical wording is the site footer: "Home Assistant is a project of the Open Home Foundation: the non-profit organization that fights for the fundamental principles of privacy, choice, and sustainability for smart homes." (https://www.home-assistant.io/) The README badge reads "A project from the Open Home Foundation" (https://github.com/home-assistant/core/blob/dev/README.rst). Short form for press and partners: "Home Assistant, an Open Home Foundation project". Never "owned by" or "a product of". Nabu Casa is described as a commercial partner that "makes official Home Assistant products", never as the owner.
