# Home Assistant: accessibility

Every output passes these. The project already treats accessibility as a feature: 2026.9 shipped "Accessibility for charts", letting screen-reader users "hear the shape of the whole trend" (https://www.home-assistant.io/blog/2026/09/02/release-20269/).

## Contrast
AA for body text. Product text tokens: primary text `--ha-color-neutral-05` on white surfaces; dark mode text #e1e1e1 on #111111. See color.md contrast table.

## Alt text
Descriptive alt text on every image; decorative images marked as such (https://developers.home-assistant.io/docs/documenting/general-style-guide).
