# Channel classes

The classes of channel the foundation and its projects use. Projects list their specific channels in `projects/<slug>/channels.md` using these classes. Purposes marked TODO are not yet defined in the comms strategy (section 1.2 and 1.3 to write).

| Class | Examples | Purpose | Default register |
|---|---|---|---|
| Email | Newsletter (types: newsletter, community update, software update, hardware release) | Regular thought leadership plus news; preferences managed at OHF level per project scope | standard |
| Website | Blog | Release blogs, long-form | standard |
| Social | Facebook, X, Bluesky, Mastodon, Threads, Instagram | TODO | standard |
| Dev social | X, Bluesky | Beta and developer-facing release news | quiet, technical |
| Video | TikTok, Instagram, YouTube, Facebook | Release videos, feature shorts | TODO |
| Live | YouTube | Release parties | loud |
| Community | Discord, Reddit, Discourse | Release posts, events, conversation | conversational |
