# ESPHome: social-profiles

The standard is `core/standards/social-profiles.md`, whose Required elements are still TODO.

**No ESPHome social profile was found.** Every place esphome.io lists where to find the project, the footer, the header social links, and the home page community section, lists Discord, GitHub and the Home Assistant forum category and nothing else. Nothing on the site links an X, Mastodon, Bluesky, Facebook, Instagram or YouTube account belonging to ESPHome. This file therefore records an absence, not a conformance gap: a standard cannot bind a surface the project does not have.

Two ways this resolves, and the interview picks one. Either ESPHome has no social presence, in which case `social-profiles` comes off `surfaces:` in `PROJECT.md` and this file is deleted. Or it has accounts that its own site does not link, which is itself the first thing the standard should require fixing.
