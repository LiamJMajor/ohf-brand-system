## Why every row is unverified
This file was populated from public sources on 2026-09-15. Verified is empty on every row and that is not an oversight: a figure read off a web page by an agent is a citation, not a verification. Verification means a person confirmed the figure is current and correct, and dated it.

Until that happens `core/escalation.md` treats every row here as unusable, which means `brand/messaging.md` cannot ship and the foundation has no usable boilerplate. This is the single highest-leverage hour anyone can spend on this project.
